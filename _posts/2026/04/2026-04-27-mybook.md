# Markdown 语法示例：标题、列表与任务清单

## 1. 多级标题演示

### 1.1 三级标题

#### 1.1.1 四级标题

##### 1.1.1.1 五级标题

###### 1.1.1.1.1 六级标题

---

## 2. 有序列表（序列）

在标准 Markdown 中，有序列表使用 `数字 + 点号` 表示，嵌套时通过缩进实现：

1. 第一层第一点  
2. 第一层第二点  
   1. 第二层第一点  
   2. 第二层第二点  
3. 第一层第三点  
   1. 第二层第三点的第一子点  
   2. 第二层第三点的第二子点  

> **注意**：实际渲染时，嵌套列表会显示为不同缩进和编号样式（如 `a.` 或 `i.`），但源码只需使用数字和缩进即可。

---

## 3. 无序列表

使用 `-`、`+` 或 `*` 加空格开头：

- 第一项  
- 第二项  
  - 缩进的子项  
  - 另一个子项  
    - 再缩进一级（用两个或四个空格）  
- 第三项  

也可以使用星号：

* 项目 A  
* 项目 B  
  * 子项目 B1  

---

## 4. 任务列表（GitHub Flavored Markdown）

在 GitHub 仓库的 `.md` 文件中，任务列表可以通过 `- [ ]` 或 `- [x]` 创建。渲染后，方框会变成可点击的复选框，点击即可切换 `[ ]` ↔ `[x]` 状态。

语法示例：

- [x] 已完成的任务（点击取消勾选）  
- [ ] 未完成的任务（点击标记完成）  
- [ ] 已放弃/作废的任务（勾选后表示完成，但也可保留为未勾选以示放弃）  

### 嵌套任务列表

- [x] 父任务 1  
  - [ ] 子任务 1.1  
  - [x] 子任务 1.2  
- [ ] 父任务 2  
  - [ ] 子任务 2.1  
  - [ ] 子任务 2.2  

> **在 GitHub 上的效果**：  
> 每个方框都可以直接点击，勾选后对应的 `[ ]` 会变为 `[x]`，并自动重新渲染为勾选状态。注意此功能仅在 GitHub 网站上生效（如仓库的 `README.md` 或 Issue/PR 描述中），普通文本编辑器不支持点击。

---

## 总结

| 语法元素         | Markdown 写法示例                     |
| ---------------- | ------------------------------------- |
| 一级标题         | `# 标题`                              |
| 二级标题         | `## 标题`                             |
| 有序列表         | `1. 第一项`<br>`2. 第二项`            |
| 无序列表         | `- 项目`<br>`  - 子项目`（缩进2空格） |
| 任务列表（GitHub）| `- [x] 已完成`<br>`- [ ] 未完成`      |

将上述代码复制到 GitHub 仓库中的 `.md` 文件内，提交后即可看到渲染结果，并且任务列表的方框支持点击切换完成状态。
